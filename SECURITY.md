# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.x (latest patch) | Yes |
| Older patch releases | No |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Email **engineering@fulton.engineering** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a minimal proof-of-concept
- Any suggested mitigations

You will receive an acknowledgement within 48 hours and a status update within
7 days. Public disclosure will be coordinated after a fix is available.
